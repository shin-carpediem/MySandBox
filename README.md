#  リッチエディタの仕様


[mattermost-mobile](https://github.com/mattermost/mattermost-mobile)でのメッセージ入力フォームと同じようなメッセージ入力エディタとする。
エディタ上でtoolbar上に表示されるアイコンは、mattermost-mobileで使われているものと同じものを使う。

エディタ上でtoolbar上で表示されるアイコンをタップして、文字の前後に挿入することのできるマークダウンは、以下。

- 見出し1 (#)
- 見出し2 (##)
- 見出し3 (###)
- 見出し4 (####)
- 太字（『*』or『_』2個ずつで囲む）
- 箇条書きリスト（-）
- 番号付きリスト（1.）
- リンク（[]()）
- 引用（>）
- コードブロック (```)
- 打ち消し線（『~』2個ずつで囲む）
- 画像（drag & drop）
